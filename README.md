# Квест «Гаррі Поттер» — Сортувальний капелюх

Нова електроніка для шапки зі старого квесту. Плата та сама, що в щитах LaserX «6-7»
(репозиторій [challenge-duel](https://github.com/PetroBosak/challenge-duel), варіант плати `hat`),
плюс вихід на мотор «рота».

## Що робить шапка
Так само, як стара прошивка (`ref/hate_hogrards.ino`, Arduino + DFPlayer + реле):

| Кнопка брелока | Фрази (по колу) | Світло |
|---|---|---|
| Грифіндор | 0001…0007 | червоний з золотими іскрами |
| Слизерин | 0008…0014 | зелений зі срібними іскрами |
| Старт | 0015…0016 | фіолетовий / синій |
| Фінал | 0017…0018 | золотий |

- Мотор ворушить «рот» у такт фразі за таблицями зі старої прошивки (`firmware/hat/mouth.h`).
  Замість реле тепер транзистор: плавний старт (ШІМ 20 кГц), потужність задається в `config.h`.
- Нова кнопка брелока перебиває поточну фразу.
- **Кнопка на шапці** (J3): замовкнути (звук, мотор і світло зупиняються).
- Чекаючи, капелюх ледь «дихає» фіолетовим (якщо підключена стрічка).
- Коди старого брелока вже вписані, тож він працює одразу. **Інший брелок:** увімкнути шапку
  з затиснутою кнопкою, далі натиснути на брелоку по черзі Грифіндор → Слизерин → Старт → Фінал.
  Після кожної кнопки мотор коротко смикнеться, коди збережуться в пам'яті.

## Залізо
- Плата: [`pcb/`](pcb/) — гербери для замовлення, BOM, схема, KiCad (50×50 мм): ESP32-C3 SuperMini, MAX98357A,
  приймач SYN480R, ключ мотора AO3400A на GPIO20 з захисним діодом SS34.
- Схема підключення: [`docs/wiring-hat.png`](docs/wiring-hat.png) (генерує `docs/tools/wiring_hat.py`).
- Клемники: J1 блок 5 В (роз'єм XT30PW-M) · J2 стрічка WS2812B · J3 кнопка · J4 друга стрічка (необов'язково) ·
  **J5 МОТОР (M+ / M−)** · динамік — у клеми модуля MAX98357A.
- Мотор живиться від +5 В блока. Ключ витримує кілька ампер, але **мотор має бути на 5 В**.
  Для мотора на 12 В потрібне окреме живлення — скажіть, переробимо.

## Звуки
Звуки вбудовані в прошивку, SD-картка і DFPlayer не потрібні.
`firmware/sounds/0001…0018.mp3` → `python firmware/tools/gen_sounds.py` → `firmware/hat/sounds.h`
(IMA ADPCM, 16 кГц; усі 18 фраз ≈ 1,5 МБ). Потрібен `ffmpeg`.
Новий трек: покласти mp3 з потрібним номером, перегенерувати `sounds.h`, за потреби поправити `mouth.h`
і групи в `config.h`, перепрошити.

## Прошивка
Бібліотеки: **FastLED 3.9.20** (не 3.10.x, вона не компілюється під C3), **rc-switch**.
Ядро `esp32:esp32` (3.x або 2.0.17).

```bash
arduino-cli compile --fqbn esp32:esp32:esp32c3:PartitionScheme=huge_app,CDCOnBoot=cdc --upload -p COMx firmware/hat
```

Монітор: `arduino-cli monitor -p COMx -c baudrate=115200`. Там видно коди брелока й номери фраз.
Нова SuperMini не прошивається: затиснути BOOT, натиснути й відпустити RST, відпустити BOOT.
